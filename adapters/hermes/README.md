# Hermes Adapter

This adapter installs the canonical `skills/aegis-alpha` package into
`$HERMES_HOME/skills/aegis-alpha` or `~/.hermes/skills/aegis-alpha`.

Hermes can discover the package-level public/internal surface directly.

On first run, Hermes should read `data/capability-guide.json` or the generated
`profile.onboarding` block before asking for API keys. Explain what Aegis Alpha
can do without APIs, what Hermes-native tools can cover, and which API groups
are recommended or required for specific investment capabilities.
